# 产品作品集 · 静态页面

按需求做的列表式静态作品集：**每个产品 = 产品介绍 → 演示视频 → 体验入口**。

纯静态，无构建步骤、无依赖，双击 `index.html` 就能看，也可以直接丢到任何静态托管（GitHub Pages / Vercel / Netlify / 对象存储）。

---


## 页面布局

每个产品**占一行**，行内横向并排放三块内容，整页压到一屏内：

```
┌──────────────────────────────────────────────────────────────────────┐
│ 01  Simple Report  一句话介绍    「标签」「标签」「标签」   角色 · 时间 │  ← 行首
│ ┌─────────────────┬┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┬┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┐                │
│ │ 产品介绍         ┊ 核心亮点         ┊ ┌───────────┐ │                │  ← 行主体
│ │ 正文……           ┊ • • • •          ┊ │  演示视频  │ │                │
│ │                  ┊                  ┊ └───────────┘ │                │
│ │                  ┊                  ┊ [ 在线体验 ]  │                │
│ └─────────────────┴┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┴┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┘                │
└──────────────────────────────────────────────────────────────────────┘
```

视觉上的几个处理，用来缓解「满」的感觉：

- **右上角标签**：产品重点词做成带描边的胶囊，加粗，一眼可见
- **淡灰面板**：把「视频 + 体验按钮」框成一个独立区块，和纯文字区分开
- **竖向分隔线**：介绍列与亮点列之间一条细线，让三栏边界清楚
- **等高分栏**：三列高度对齐，块感整齐，不是参差的文字流

用 Chrome 无头模式实测的总高度（视口宽度 ≥ 1200px 时三列并排）：

| 视口 | 三行总高 | 是否一屏看完 |
| --- | --- | --- |
| 1920×1080 | 893px | ✅ |
| 1440×900 | 893px | ✅ |
| 1536×864 | 893px | 超 29px |
| 1366×768 | 893px | 超 125px |
| 1180×820 | 915px | 超 95px |
| 1000×800 | 1043px | 超 243px（列变窄、换行变多） |
| 840×1000 / 手机 | 两列 → 单列堆叠 | 需滚动（正常） |

> 任何宽度下**都没有横向溢出**（无左右滚动条）。

### 想再矮一点 / 高一点？

改 `assets/css/style.css` 顶部的两个变量即可，不用动其它任何地方：

```css
:root {
  --maxw:    1320px;  /* 页面宽度。调大 → 文字列更宽、换行更少 → 整页更矮更透气 */
  --video-w:  196px;  /* 视频列宽。调小 → 整页更矮；调大 → 视频更醒目 */
}
```

> 实测到的规律（按有效性排序）：
> 1. **`--maxw` 是最被低估的杠杆** —— 加宽页面会让每一栏都变宽、文字少换行，
>    行高跟着降。实测把 1240 → 1320px，「心愿」的介绍从 7 行降到 5 行，
>    整页从 906px 降到 884px，**同时又更舒展**。
> 2. **`--video-w` 决定每行的地板高度** —— 视频 + 按钮在淡灰面板里垂直堆叠，
>    这个高度是每行的最低值（实测 164px），三行里有两行由它决定。
> 3. 当视频列小到约 150px 后，地板高度改由「产品介绍」列决定，再调小就没用了。

其它可调项（同样在 `style.css`）：`.intro p` 字号（13px）、`.highlights li`（12.5px）、
`.card` 的 `padding` 与 `margin-top`（行间距）、`.row-body` 的 `gap`（列间距）。

## 怎么填内容

打开 `data/products.js`，只改这一个文件。

### 1. 头部个人信息

```js
profile: {
  name: '张三',
  title: '产品经理',
  bio: '一句话介绍……',
  email: 'you@example.com',      // 可选
  github: 'https://github.com/…', // 可选
  resumeUrl: '',                  // 可选，简历链接
}
```

### 2. 演示视频

有两种填法：

| 情况 | 怎么填 |
| --- | --- |
| 本地视频文件（推荐） | 把文件放到 `assets/video/`，然后 `video: { type: 'file', src: 'assets/video/xinyuan.mp4', poster: '' }` |
| B 站 / YouTube | 在视频页点「分享 → 嵌入」，复制 iframe 里的 `src` 网址，`video: { type: 'embed', src: 'https://player.bilibili.com/player.html?bvid=…' }` |
| 还没准备好 | 保持 `video: { type: 'none' }`，页面会显示「演示视频待补充」的虚线占位框 |

`poster` 是视频封面图（可选），填 `assets/img/xxx.jpg`；不填就用浏览器显示的视频首帧。

> 建议本地视频文件名和 `id` 保持一致、用英文，避免中文名在 URL 里被编码后出现兼容问题。

### 3. 体验入口

```js
link: { url: 'https://xxx.com', label: '在线体验' },
```

- `url` 可以是网页，也可以是 apk / 下载包地址；`label` 就是按钮上的字。
- `url` 留空会显示「体验入口待补充」按钮，方便你一眼看出还没配的产品。
- 完整地址不在页面上占一行（横向布局里太挤），鼠标悬停按钮即可看到。

### 4. 新增一个产品

复制 `products` 数组里任意一个 `{ ... }` 对象，粘在末尾，改掉 `id`（英文，别重复）和内容即可。列表顺序 = 数组顺序。

## 本地预览

直接双击 `index.html` 即可。

如果浏览器对本地视频/iframe 有限制，起个本地服务更稳：

```bash
cd 作品集
python -m http.server 8080
# 打开 http://localhost:8080
```

## 自检（可选）

改完 `products.js` 后可以跑一下冒烟测试，确认页面渲染正常、没有断链：

```bash
node tools/smoke_test.js .          # 校验渲染结果 + 视频文件是否真的存在（推荐每次改完都跑）
node tools/smoke_test_filled.js .   # 校验留空降级 / 本地视频 / 嵌入视频几条分支
```

## 部署

> 📌 **要挂到公网（放进简历）请看 [`deploy/DEPLOY.md`](deploy/DEPLOY.md)** ——
> 里面有实测到的服务器现状、两条上线路径、证书与 DNS 的具体命令，以及上线自查清单。

把整个 `作品集/` 目录上传到任意静态托管即可，不需要后端。

- **GitHub Pages**：推到仓库 → Settings → Pages → 选分支根目录
- **Vercel / Netlify**：直接拖拽文件夹，或连仓库，无需构建命令，输出目录填 `.`
- 视频较大时建议传 B 站/YouTube 用 `embed`，或把 mp4 放对象存储（避免拖慢静态托管）
- 注意：当前三个视频共约 32 MB，若托管平台对单文件大小有限制，改走 `embed` 更稳
